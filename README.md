# Learning Canadian French

Personal tools and materials for learning Canadian (Québécois) French: vocabulary lists, grammar exercises, and small browser-based tools for drilling pronunciation and testing recall.

## Structure

### `anki-words/`
Tab-separated vocabulary lists (`day-1.txt` … `day-7.txt`), one entry per line:
```
<French word/phrase>\t<English translation>\t[sound:<audio-file>.webm]
```
The third column references an audio clip generated by `pronunciation-generator/` and is formatted for import into [Anki](https://apps.ankiweb.net/) as a flashcard deck.

### `grammar-exercises/`
Grammar practice, split into two styles:
- `heminway/<lesson>/` — organized by textbook/source and lesson. Each numbered file pairs an English prompt with the French translation attempt and a correction/note, e.g.:
  ```
  1. We refuse the invitation.
     Nous refusons l'invitation. // Fixed: proper apostrophe (l')
  ```
- `translation-drills/<topic>/<n>.json` — machine-readable exercises consumed by `translation-drill.html`, one folder per grammar topic scoped as `<verb>-<tense>` (e.g. `etre-present/`), numbered files within it (`1.json`, `2.json`, …) so more exercise sets can be added to the same topic over time. Each entry is:
  ```json
  { "en": "He is a cosmonaut.", "fr": "Il est cosmonaute.", "vocab": [{ "fr": "cosmonaute", "en": "cosmonaut" }] }
  ```
  `vocab` lists non-obvious words in the sentence so they can be viewed/heard as a hint without giving away the full translation.

### `pronunciation-generator/`
Node.js script (`make-pronunciation-files.js`) that reads an Anki-formatted `.txt` file, uses a headless browser (Puppeteer) with speech synthesis to speak each French/English pair, records the audio, and saves it as `.webm` files (plus a concatenated file) alongside the source list — producing the `[sound:...]` clips referenced in `anki-words/`.

Usage:
```
cd pronunciation-generator
npm install
node make-pronunciation-files.js <relative-path-to-txt>
```

### `audio-drill.html`
Standalone browser page (no build step) that loads one or more vocabulary `.txt` files and reads each French/English pair aloud on a loop using the Web Speech API, with configurable repetitions and optional shuffling — useful for passive listening practice.

### `vocab-quiz.html`
Standalone browser page that loads a vocabulary `.txt` file and quizzes you: shows the English term, you type the French translation, and it scores your answers (with an override checkbox for near-misses).

### `translation-drill.html`
Standalone browser page that loads a `translation-drills/<topic>/*.json` exercise and quizzes you on full-sentence translation (harder than single-word recall): you type the French translation of each English sentence, check your answers, and hear the correct French read aloud (individually or all at once). Non-obvious vocabulary per sentence is shown (and speakable) alongside the prompt so you can pick up new words while attempting the sentence.

## Usage

Open `audio-drill.html`, `vocab-quiz.html`, or `translation-drill.html` directly in a browser and load the relevant file (`anki-words/*.txt` for the first two, `grammar-exercises/translation-drills/<topic>/*.json` for the third). No server or build step required.
