# Learning Canadian French

Personal tools and materials for learning Canadian (Québécois) French: vocabulary lists, grammar exercises, and small browser-based tools for drilling pronunciation and testing recall.

## Structure

### `anki-words/`
Tab-separated vocabulary lists (`day-1.txt` … `day-7.txt`), one entry per line:
```
<French word/phrase>\t<English translation>\t[sound:<audio-file>.webm]
```
The third column references an audio clip generated by `pronunciation-generator/` and is formatted for import into [Anki](https://apps.ankiweb.net/) as a flashcard deck.

### `grammar-exercises/`
Grammar practice:
- `translation-drills/<cefr-level>/<topic>/<n>.json` — machine-readable exercises consumed by `translation-drill.html`, top-level folders by CEFR level (`a1/`, later `a2/`, `b1/`, `b2/`), then one folder per grammar topic scoped as `<verb>-<tense>` (e.g. `a1/etre-present/`), numbered files within it (`1.json`, `2.json`, …) so more exercise sets can be added to the same topic over time. Each entry is:
  ```json
  { "en": "He is a cosmonaut.", "fr": "Il est cosmonaute.", "vocab": [{ "fr": "cosmonaute", "en": "cosmonaut" }] }
  ```
  `vocab` lists non-obvious words in the sentence so they can be viewed/heard as a hint without giving away the full translation.

### `reading-exercises/`
Read-aloud passages consumed by `reading-trainer.html`, laid out like the translation drills: `<cefr-level>/<topic>/<n>.json` (e.g. `a1/nasale-in/1.json`). Each file is:
```json
{
  "title": "Nasal [ɛ̃] — in, im, yn, ym, ain, aim, ein, eim (set 1)",
  "sounds": ["in", "im", "ain"],
  "focus": "What is being trained, and the traps to watch for.",
  "sentences": [{ "fr": "Sylv[ain] a c[in]q ans…", "en": "Sylvain is five…" }],
  "vocab": [{ "fr": "demain", "en": "tomorrow" }]
}
```
Square brackets in `fr` mark the letters being trained. They're shown highlighted and removed before the text is spoken. They're marked by hand rather than pattern-matched, because the same letters aren't always the target sound (*pain* vs. *semaine*).

### `pronunciation-generator/`
Node.js script (`make-pronunciation-files.js`) that reads an Anki-formatted `.txt` file, uses a headless browser (Puppeteer) with speech synthesis to speak each French/English pair, records the audio, and saves it as `.webm` files (plus a concatenated file) alongside the source list — producing the `[sound:...]` clips referenced in `anki-words/`.

**Windows only.** The script records audio by capturing the system's own output in real time (`getUserMedia` with `chromeMediaSource: 'system'`), which relies on Chrome's Windows-specific loopback audio capture. This does not work on macOS or Linux, and does not work in a headless/CI environment — it needs a real desktop session with audio actually playing out loud.

#### Requirements

| Requirement | Needed for | How to get it |
|---|---|---|
| **Windows 10 or 11** | Running the script at all — the audio-capture method below only works on Windows. | Already your OS; nothing to install. |
| **[Node.js](https://nodejs.org/)** (LTS release) | Running `npm install` and `node make-pronunciation-files.js` — the script itself. | Download the LTS installer from [nodejs.org](https://nodejs.org/) and run it (installs `npm` too). |
| **Internet access, once, for `npm install`** | Downloading Puppeteer's own bundled Chromium, which is the browser the script drives. No separate Chrome/Edge install needed. | Just run `npm install` with a working internet connection; after that it works offline. |
| **Windows text-to-speech voice: "Français (Canada)"** | Producing the French audio — the script asks for an `fr-CA` voice, and without one installed Windows falls back to a wrong-accent or English voice (or none at all). | Settings → Time & Language → Speech → Manage voices → Add voices → search **"Français (Canada)"** → install. |
| **Windows text-to-speech voice: "English (United States)"** | Producing the English audio for each entry's second clip (`en-US`). Often present by default, but check. | Same screen as above — Settings → Time & Language → Speech → Manage voices → Add voices → search **"English (United States)"**. |
| **Chrome restarted after installing voices** | Letting the browser actually see newly installed voices — it only reads the OS voice list on (re)start. | Fully quit and reopen Chrome once voices are installed. Verify with `speechSynthesis.getVoices().filter(v => v.lang.startsWith('fr') || v.lang.startsWith('en'))` in DevTools' console — confirm an entry with `lang: "fr-CA"` appears. |
| **System audio output, unmuted, at a reasonable volume** | The actual recording step — the script captures whatever is audibly playing, so a muted/silent system produces empty `.webm` files. | Check Windows volume mixer isn't muted before running the script. |

Usage:
```
cd pronunciation-generator
npm install
node make-pronunciation-files.js <relative-path-to-txt>
```

### `audio-drill.html`
Standalone browser page (no build step) that loads one or more vocabulary `.txt` files and reads each French/English pair aloud on a loop using the Web Speech API, with configurable repetitions and optional shuffling — useful for passive listening practice.

### `vocab-quiz.html`
Standalone browser page that loads a vocabulary `.txt` file and quizzes you: shows the English term, you type the French translation, and it scores your answers (with an override checkbox for near-misses).

### `translation-drill.html`
Standalone browser page that loads a `translation-drills/<topic>/*.json` exercise and quizzes you on full-sentence translation (harder than single-word recall): you type the French translation of each English sentence, check your answers, and hear the correct French read aloud (individually or all at once). Non-obvious vocabulary per sentence is shown (and speakable) alongside the prompt so you can pick up new words while attempting the sentence.

### `reading-trainer.html`
Standalone browser page that loads a `reading-exercises/` passage for read-aloud practice. The sounds being trained are highlighted in red (toggle them off to try spotting them yourself). Click any sentence to hear it, or "Read whole text" to hear the passage one sentence at a time; the sentence being read is highlighted along with its English translation, which can be shown or hidden.

## Usage

Open `audio-drill.html`, `vocab-quiz.html`, `translation-drill.html`, or `reading-trainer.html` directly in a browser and load the relevant file (`anki-words/*.txt` for the first two, `grammar-exercises/translation-drills/<level>/<topic>/*.json` for the third, `reading-exercises/<level>/<topic>/*.json` for the fourth). No server or build step required.

### Online (GitHub Pages)
The browser tools are also published to GitHub Pages by `.github/workflows/pages.yml` on every push to `master`, with a landing page (`index.html`). The deploy step runs `.github/scripts/build-manifest.js` to generate a `manifest.json` listing every `anki-words/` list, translation-drill set, and reading exercise, so the online tools offer them in a picker — nothing needs downloading. New files show up automatically on the next push. (Locally there's no manifest, so the picker is hidden and you choose files as before.) The pronunciation generator isn't included — it needs Windows and Node.

One-time setup: repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
